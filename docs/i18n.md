# Traducción (es / pt-BR)

## Uso

- Banderas 🇦🇷 / 🇧🇷 en header (desktop), header mobile y login/registro.
- La elección se guarda en la cookie `SERVIDO_LOCALE` (`es` o `pt-BR`).

## Archivos

- `messages/es.json` — textos en español
- `messages/pt-BR.json` — portugués brasileño
- `i18n/config.ts` — locales y cookie
- `i18n/request.ts` — carga de mensajes (next-intl)
- `components/layout/locale-flag-toggle.tsx` — selector

## Migrar una pantalla

1. En el componente cliente: `import { useTranslations } from "next-intl"`
2. `const t = useTranslations("nombreSeccion")` (o `"common"`, `"header"`, etc.)
3. Reemplazar strings: `t("clave")` con parámetros `{ name: "..." }` si hace falta
4. Agregar la misma clave en **ambos** JSON
